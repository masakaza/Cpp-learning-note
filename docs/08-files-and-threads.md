# 08 · 文件操作与线程

## 1. 文件流

`<fstream>` 提供文件输入输出流：

- `std::ifstream`：读取文件；
- `std::ofstream`：写入文件；
- `std::fstream`：读写文件。

文本文件适合保存可读文本；二进制文件按字节处理数据。打开文件时应检查是否成功，并明确使用何种打开模式。直接把对象的内存字节写入文件并不总是可移植：对象可能含有指针、填充字节或平台相关表示。需要长期保存或跨平台交换时，应设计明确的序列化格式。

## 2. 基本检查方式

```cpp
#include <fstream>
#include <iostream>

int main() {
    std::ofstream out("example.txt");
    if (!out) {
        std::cerr << "无法打开文件进行写入\n";
        return 1;
    }
    out << "Hello file\n";
}
```

文件对象离开作用域时会自动关闭文件。实际使用中应检查读写状态，并考虑文件路径、权限和当前工作目录。

## 3. `std::thread`

`<thread>` 提供标准线程设施。创建 `std::thread` 后，线程会开始执行指定的可调用对象。线程对象销毁前必须被 `join()` 或 `detach()`；若一个仍然 joinable 的线程对象直接析构，程序会调用 `std::terminate()`。

- `join()`：等待线程执行结束，调用方在等待期间阻塞。
- `detach()`：分离线程，让它在后台继续执行；必须确保线程访问的对象不会提前销毁。
- `std::ref(x)`：当需要按引用传递参数时，可用它包装引用。

`join()` 只保证等待对应线程完成，并不自动解决多个线程同时访问共享数据的竞争问题。共享可变状态时，需要考虑互斥锁、原子变量或其他同步机制。
