# 01 · C++ 基础语法

## 1. 程序的基本结构

最小程序通常包含头文件、入口函数和返回状态：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++\n";
    return 0;
}
```

`main` 是程序入口。`std::cout` 用于输出，`std::cin` 用于输入；`#include <iostream>` 提供这些流对象的声明。学习时可以使用 `using namespace std;` 简化书写，但在大型项目和头文件中，显式写 `std::` 通常更稳妥。

## 2. 数据类型与变量

- 整型：`short`、`int`、`long`、`long long`，具体宽度受实现影响。
- 浮点型：`float`、`double`、`long double`。浮点数通常存在精度误差，不适合直接用 `==` 判断一般计算结果。
- 字符型：`char` 表示一个字符编码单元；字符字面量使用单引号，如 `'A'`。
- 布尔型：`bool` 的值为 `true` 或 `false`。
- 字符串：C++ 风格字符串可使用 `std::string`，需要 `#include <string>`。

`sizeof(x)` 返回对象或类型占用的字节数，类型是 `std::size_t`。不要假设所有平台上的 `int`、指针大小都相同。

## 3. `const` 与类型转换

`const` 表示不能通过该名字修改对象。它能帮助表达接口意图、减少误修改。类型转换需要留意信息丢失，例如浮点数转整数会丢弃小数部分。

```cpp
const int max_count = 10;
double value = 3.8;
int n = static_cast<int>(value); // n 为 3
```

优先使用清晰的显式转换，避免不加判断地混用不同类型。

## 4. 运算符

基础代码覆盖算术、比较、逻辑、自增/自减和三目运算符。

- `==` 是比较，`=` 是赋值。
- `&&`、`||` 具有短路求值特性：在结果已确定时，右侧表达式可能不执行。
- `++x` 先递增再产生表达式结果；`x++` 产生旧值后递增。对简单整数，单独使用时通常没有可见差异；在复杂表达式里优先避免依赖难读的求值顺序。
- 三目表达式 `condition ? a : b` 用于根据条件选择表达式结果。

## 5. 流程控制

`if/else` 处理条件分支；`switch` 适合离散的整型、枚举等情况；`for`、`while` 和 `do while` 用于循环。`break` 结束最近一层循环或 `switch`，`continue` 跳过本轮循环剩余部分。

使用循环时，重点检查：
1. 循环初始状态是否正确；
2. 退出条件能否最终成立；
3. 每轮是否更新了相关变量；
4. 数组下标是否越界。

`goto` 可以跳转到标签，但一般业务逻辑中应优先采用结构化控制流程。

## 6. 数组

数组存储固定数量、同类型的元素。普通数组下标从 `0` 开始，有效下标为 `0` 到 `N-1`。二维数组可理解为由多个定长数组组成。

```cpp
int values[3] = {10, 20, 30};
for (int i = 0; i < 3; ++i) {
    std::cout << values[i] << '\n';
}
```

常见练习包括遍历、求和、最大/最小值、元素逆置和冒泡排序。函数接收普通数组时，数组通常会退化为指针，因此要把长度作为另一个参数传递，或使用 `std::array` / `std::vector`。
