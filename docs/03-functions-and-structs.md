# 03 · 函数、模块与结构体

## 1. 函数声明和定义

声明告诉编译器函数的名称、参数和返回类型；定义提供函数体。函数声明通常写在头文件中，定义放在 `.cpp` 文件中。

```cpp
// math_utils.h
#pragma once
int add(int a, int b);

// math_utils.cpp
#include "math_utils.h"
int add(int a, int b) {
    return a + b;
}
```

头文件应使用包含保护（`#pragma once` 或宏保护），避免重复包含导致的声明冲突。项目编译时需要把相关 `.cpp` 文件一起交给编译器。

## 2. 参数传递

- 值传递：函数获得参数副本，修改副本不影响调用者。
- 指针传递：传递地址，函数可以通过有效指针访问原对象；需约定空指针是否允许。
- 引用传递：传递对象别名，语法直观。
- `const T&`：适合只读地传递较大的对象。
- 默认参数和占位参数：默认参数可在调用时省略尾部参数；未命名的参数可用于暂时不使用参数值的场景。

## 3. 函数重载

同一作用域中可以定义多个同名函数，只要参数列表具有可区分性。仅返回类型不同不能构成重载。编译器根据调用时的参数类型、数量等选择匹配的函数。

```cpp
void print(int value);
void print(double value);
```

通过引用限定或 `const` 形成重载时，需要特别注意实际参数的类型与可行的重载匹配规则。

## 4. 结构体

`struct` 将多个相关字段组合为一个类型。C++ 中 `struct` 的成员默认是 `public`，而 `class` 的成员默认是 `private`；除此之外，两者都能拥有成员函数、构造函数等。

结构体可以嵌套、构成数组、通过指针访问，也可以作为函数参数。对于只读的大型结构体参数，可考虑 `const T&`，避免复制。
