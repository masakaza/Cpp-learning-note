# 05 · 运算符重载

运算符重载允许自定义类型定义 `+`、`==`、`<<` 等运算符的行为。它不会改变运算符的优先级、结合性或操作数数量，也不能凭空创造新的运算符。

## 1. 成员函数与非成员函数

部分运算符可以实现为成员函数或非成员函数。选择时要考虑左右操作数的类型、是否需要访问私有成员，以及是否希望左操作数支持隐式转换。

例如，`a + b` 可以设计为成员函数，也可以设计为非成员函数。流插入运算符 `std::ostream& operator<<(std::ostream&, const T&)` 通常写成非成员函数，因为左操作数是 `std::ostream`。

## 2. 重载输出运算符

```cpp
#include <iostream>

class Point {
public:
    int x{}, y{};
};

std::ostream& operator<<(std::ostream& out, const Point& p) {
    out << '(' << p.x << ", " << p.y << ')';
    return out;
}
```

返回流引用，才能支持 `std::cout << p << '\n';` 这样的连续输出。通常将待输出对象作为 `const` 引用，避免复制并允许输出常量对象。

## 3. 自增运算符

惯例是用一个虚拟的 `int` 参数区分后置自增：

```cpp
T& operator++();    // 前置：修改后返回当前对象引用
T operator++(int);  // 后置：通常保存旧值，递增后返回旧值副本
```

前置形式通常更高效；后置形式需要表达递增前的值。对自定义类型应保持与用户预期一致的语义。

## 4. 关系、算术与赋值

重载 `==`、`<` 等时，行为应符合类型的自然含义，并尽量保持一致性。赋值运算符通常返回 `T&`，并且要正确处理资源管理、自赋值和链式赋值。若类没有自己管理的资源，优先使用编译器生成的赋值操作，而不是无必要地手写。
