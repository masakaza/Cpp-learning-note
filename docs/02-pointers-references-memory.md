# 02 · 指针、引用与内存

## 1. 指针是什么

指针对象保存一个地址。`&x` 取得对象地址，`*p` 在 `p` 指向有效对象时访问该对象。

```cpp
int x = 42;
int* p = &x;
*p = 50; // 修改 x
```

指针本身也有类型，例如 `int*` 指向 `int`。指针运算与指向对象的类型有关；对数组指针做运算时，只能在同一数组范围内或尾后位置进行合法的指针运算。

## 2. 空指针、悬空指针与野指针

- 空指针：用 `nullptr` 表示不指向对象。
- 未初始化指针：值不确定，不能解引用。
- 悬空指针：指向的对象已销毁或内存已释放。
- 越界访问：通过指针或下标访问合法范围之外的内存。

不要解引用空指针或无效指针。释放动态内存后应避免继续使用该地址；将指针设为 `nullptr` 只能清理当前指针变量，不能修复其他副本中保存的悬空地址。

## 3. `const` 与指针

```cpp
const int* p1 = &x; // 不能通过 p1 修改所指对象
int* const p2 = &x; // p2 不能改指向，但可以通过它修改 x
const int* const p3 = &x; // 两者都不能改
```

判断技巧：先看 `const` 修饰的是指针所指类型，还是指针变量本身。

## 4. 引用

引用是已有对象的别名，声明时必须初始化，通常不能改为引用另一个对象。函数参数使用引用，可以避免不必要的对象拷贝，也可以让函数修改调用者的对象。

```cpp
void increment(int& value) {
    ++value;
}
```

常量引用 `const T&` 可绑定到对象而不允许通过该引用修改对象，也常用于高效传递大型只读对象。引用不是“可空指针”；不要把它当作可重新绑定的变量。

## 5. 动态内存与资源管理

`new` 分配对象，`delete` 释放单个对象；`new[]` 与 `delete[]` 必须配对使用。忘记释放会造成泄漏，重复释放或释放不匹配会导致未定义行为。

现代 C++ 优先采用自动存储期对象、标准容器和智能指针管理资源。例如 `std::vector<T>` 管理动态数组，`std::unique_ptr<T>` 表达独占所有权。学习 `new/delete` 仍有价值，但实际项目应优先考虑 RAII（资源获取即初始化）。
