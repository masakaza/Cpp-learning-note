# 04 · 类与面向对象

## 1. 封装与访问权限

类把数据和操作数据的函数组合在一起。`public` 成员构成外部可使用的接口；`private` 成员只允许类自身及其友元访问；`protected` 还允许派生类访问。封装的目标不是单纯隐藏数据，而是让对象通过受控接口维持有效状态。

## 2. 构造与析构

- 构造函数在对象初始化时执行。
- 析构函数在对象生命周期结束时执行。
- 初始化列表在成员初始化阶段直接初始化成员，尤其适用于 `const` 成员、引用成员和没有默认构造函数的成员对象。
- 构造函数可以重载，但不能有返回类型。

成员对象会按照声明顺序初始化，而不是初始化列表中的书写顺序。析构顺序与构造顺序相反。

## 3. 拷贝、赋值与资源所有权

拷贝构造用于用一个已有对象初始化新对象；赋值运算符用于把值赋给一个已经存在的对象。编译器生成的默认拷贝通常逐成员拷贝。若类直接拥有裸指针并以其管理动态资源，逐成员拷贝会让多个对象指向同一资源，可能引发重复释放或悬空指针。

常见解决思路：
1. 遵循 **Rule of Zero**：用 `std::string`、`std::vector`、智能指针等成员管理资源，让编译器生成合适的特殊成员函数；
2. 如果必须手动管理资源，正确实现析构、拷贝构造和拷贝赋值（并考虑移动构造/移动赋值），保证异常安全和自赋值安全；
3. 对不允许复制的类型，显式删除拷贝操作。

注意：赋值运算符应处理目标对象原先持有的资源，不能只 `new` 新内存而丢失旧指针，否则会泄漏。返回 `*this` 的引用可以支持 `a = b = c` 这样的链式赋值。

## 4. `this`、静态成员和友元

`this` 指向当前对象。静态成员属于类本身，而非每个实例各自一份；非静态成员函数可以访问当前对象的成员。友元函数不是类成员函数，但可获得访问类私有/保护成员的权限，应谨慎使用。

`const` 成员函数承诺不通过当前对象修改普通成员，适合查询接口。

## 5. 继承与多态

继承表达派生类与基类之间的关系。多态通常通过基类指针或引用调用虚函数实现，使实际执行版本取决于对象的动态类型。

- 需要通过基类接口多态销毁派生对象时，基类析构函数通常应为 `virtual`。
- 纯虚函数使类成为抽象类，不能直接创建该类对象。
- 菱形继承可能造成重复基类子对象；虚继承是解决特定重复基类问题的机制，但会增加设计复杂度。
- 继承应表达真正的“是一种”关系；仅为了复用代码时，也要考虑组合是否更合适。
